# سایت دانستنی‌ها

یک سایت ساده HTML / CSS / JavaScript درباره دانستنی‌های جذاب.

## باز کردن در Visual Studio Code

1. Visual Studio Code را باز کن.
2. از منوی File گزینه Open Folder را بزن.
3. پوشه `danestaniha` را انتخاب کن.
4. فایل `index.html` را باز کن.
5. اگر افزونه Live Server را داری، روی صفحه راست‌کلیک کن و Open with Live Server را بزن.
6. اگر Live Server نداری، فایل `index.html` را با مرورگر باز کن.

## ساختار فایل‌ها

- `index.html` صفحه اصلی
- `css/style.css` ظاهر سایت
- `js/data.js` مطالب و دسته‌بندی‌ها
- `js/app.js` عملکرد دکمه‌ها، جست‌وجو و دانستنی تصادفی

برای دیدن مطالب هر موضوع، روی کارت همان موضوع در صفحه خانه کلیک کن.
